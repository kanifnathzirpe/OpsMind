# OpsMind

AI Operating System for Modern Merchants.

OpsMind helps merchants monitor revenue, detect fraud, recover failed payments, forecast cash flow, and interact with their business using AI-powered agents.

## Features

- AI Copilot
- Revenue Recovery
- Fraud Intelligence
- Finance Controller
- Analytics Dashboard
- Knowledge Base (RAG)

## Tech Stack

Frontend:
- Next.js
- Tailwind
- shadcn/ui

Backend:
- FastAPI
- PostgreSQL

AI:
- Gemini
- LangGraph
